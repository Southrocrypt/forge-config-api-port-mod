# Forge Config API Port — Cross-Platform Config

[![Download Latest](https://img.shields.io/github/v/release/Southrocrypt/forge-config-api-port-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Southrocrypt/forge-config-api-port-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Ports the Forge Config API to Fabric and NeoForge, giving mods a single config format across loaders.

![Forge Config API Port — Cross-Platform Config Preview](https://cdn.modrinth.com/data/ohNO6lps/images/201d6c2cd17e10032e9651bc0070007b4774286c_350.webp)

## Features

- Forge TOML config format available on Fabric
- Single config codebase works on all loaders
- Config GUI integration via Cloth Config API
- Automatic config migration between versions
- Used by ports of major Forge tech mods

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
